# Phase 2 — adaptation note (Iris)

Wonder's Phase-2 report (report-phase2.md) re-invented the houses and several citizens
(e.g. "Megh the roofer", Ferry/Bazar/School/Workshop houses). That conflicts with the
locked canon from the World Bible + Cast round (Builders / Truth / Culture /
Society & Wildcards, and the 24 identity cards) and with the live v1 site.

Decision: canon wins. Phase 2 was built using the report's STRUCTURE (profile page
section order, groups system, Days 3–5 story beats, build order) but with all names,
houses, jobs, goals, rivals, promises and flaws taken from the locked cast cards.
The 6 groups were re-founded by canon citizens in canon roles. Days 3–5 posts were
written in the cast's own voices following the same three arcs.
